# Sara's Elegant Estates

### 📋 PROMPT PARA GERAÇÃO DE SITE IMOBILIÁRIO (COPIE A PARTIR DAQUI)

**Atue como um Desenvolvedor Web Sênior e Especialista em UI/UX.**
Crie a estrutura, o design e o conteúdo para o site de uma imobiliária premium chamada "Sara Fernandes Imóveis". O site deve ser altamente sofisticado, focado em conversão e construído com a abordagem "Mobile-First" (prioridade para celulares).

Abaixo estão os requisitos técnicos e visuais divididos por tópicos:

#### 1. Identidade Visual e Estilo

* **Cores Principais:** Dourado/Ouro (para botões de ação e destaques) e Cinza/Prata (para textos e detalhes).
* **Cor de Fundo:** Branco ou Off-White para garantir um visual *clean* e destacar as fotos dos imóveis.
* **Tipografia:** Fontes elegantes, combinando uma Serifada clássica (para títulos) com uma Sans-Serif moderna e legível (para o corpo do texto).
* **Estilo Geral:** Luxuoso, minimalista, transmitindo confiança, credibilidade e atendimento exclusivo (estilo imobiliária boutique).

#### 2. Arquitetura da Informação (Menu Principal)

O cabeçalho deve ser fixo (sticky) e conter a Logo, o número "CRECI-PI 3291" e as seguintes abas de navegação:

* Comprar
* Alugar
* Avaliação de Imóveis
* Quem Somos
* Contato

#### 3. Seção Principal (Hero Section)

* **Fundo:** Uma imagem de alta qualidade de uma varanda sofisticada ou sala de estar iluminada.
* **Título Principal:** "Sua Próxima Conquista Começa Aqui."
* **Motor de Busca (Filtros):** Uma caixa de pesquisa limpa flutuando sobre a imagem com os seguintes campos:
* **Finalidade:** Comprar ou Alugar.
* **Tipo de Imóvel:** (Opções exatas: Apartamento; Casa; Casa em condomínio; Loja, Sala Comercial e/ou Galpão; Lote e terreno; Sítio, chácara e/ou fazenda).
* **Localização:** Campo de texto para Bairro/Cidade.
* **Botão de Ação:** "Buscar Imóvel" (na cor dourada).



#### 4. Seções da Página Inicial (Home)

* **Catálogo Destaque:** Exibir 3 a 6 *cards* de imóveis. No layout mobile, eles devem rolar lateralmente (swipe). Cada card deve ter foto grande, preço destacado, localização e ícones básicos (quartos/vagas).
* **Avaliação de Imóveis:** Uma seção dedicada à captação de leads. Deve conter um formulário simples com os campos: "Nome do Cliente", "Endereço" e "Telefone". O botão de envio deve ser dourado com o texto: "Solicitar Avaliação via WhatsApp" (este botão não envia e-mail, ele redireciona os dados preenchidos para uma mensagem de WhatsApp).
